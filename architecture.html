evidencia_pipe — Architecture

Pipeline de ingestão DSpace → MinerU → Qdrant → LLM · FastAPI :8020 · Celery · GPU Worker

API Layer

  • • FastAPI :8020 — BackgroundTasks + Celery
  • • POST /dspace/item/{uuid} → chain por PDF
  • • GET /status/{job_id} — polling de progresso
  • • GET /result/{job_id} — markdown extraído
  • • POST /enrich/{job_id} — só LLM stage

Orquestração Celery

  • • Broker: Redis :6379 (DB 0)
  • • Job Store: Redis DB 1 (TTL 7 dias)
  • • Filas: download, extract, llm, gpu
  • • Chain encadeia ctx entre stages
  • • Worker Light: -c 4 (I/O concurrent)
  • • Worker GPU: -c 1 (1 modelo na VRAM)

Pipeline de Ingestão

  • • ① Download bitstream do DSpace REST
  • • ② Extração MinerU (markdown + JSON)
  • • ③ Enriquecimento DeepSeek (best-effort)
  • • ④ Chunking (1200 chars, overlap 250)
  • • Filtros de qualidade (OCR, tamanho)
  • • Embeddings bge-m3 dense + sparse
  • • Upsert no Qdrant collection evidencia_chunks
